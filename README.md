# -north-star-financial-services-grc
    Independent GRC portfolio project assessing cybersecurity risks and planning remediation for a fictional financial-services company.
Northstar Financial Services — IT GRC Risk & Compliance Assessment
## Project Overview
This fictional, portfolio-based assessment simulates cybersecurity governance, risk, and compliance activities for a financial services organization. It uses NIST Cybersecurity Framework (CSF) and NIST SP 800-53 as reference frameworks.
## Project Deliverables
The Excel workbook contains the following worksheets:
- Project Charter — assessment purpose and scope
- Asset Inventory — assets within the assessment
- Risk Scoring — likelihood and impact methodology
- Risk Register — documented risks, scores, ratings, ownership, and treatments
- Evidence Tracker — evidence collection tracking
- Control Assessment — review of security controls
- Gap Assessment — identified areas for improvement
- Remediation Plan — planned corrective action
- POA&M — Plan of Action and Milestones
- Vendor Risk — third-party risk assessment
- Dashboard — summarized risk and remediation metrics
## Key Dashboard Results
Illustrative data in the supplied portfolio workbook:
- 10 assessed risks
- 2 critical risks
- 8 high risks
- 7 open remediation findings
## Skills Demonstrated
Cybersecurity risk assessment, risk scoring, NIST framework alignment, control assessment, gap analysis, remediation and POA&M tracking, third-party risk evaluation, and executive reporting.
## How to Review the Project
1. Download the Excel (.xlsx) workbook from this repository.
2. Open it in Microsoft Excel or import it into Google Sheets.
3. Review the Dashboard and Risk Register worksheets first.
4. Examine Control Assessment, Gap Assessment, Remediation Plan, and POA&M for supporting detail.
Spreadsheet compatibility: GitHub previews do not execute spreadsheet formulas. Download the workbook and open it in a spreadsheet application to view and recalculate results. The original workbook contains spreadsheet formulas, including shared formulas.

## Disclaimer
This is a simulated portfolio project. The organization, issues, control assessments, and outcomes are illustrative and do not represent a real client engagement.
